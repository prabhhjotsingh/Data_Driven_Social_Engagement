# Data-Driven Social Engagement Analysis

## 1. Project Overview

This project analyzes social media content performance using data-driven
techniques.

The analysis focuses on:

- Content engagement
- Viral performance
- Audience relatability
- Follower growth
- Content format
- Hook type
- Posting time
- Content topics

The objective is to identify the characteristics associated with stronger
social media performance and provide actionable recommendations.

---

## 2. Dataset

The project uses two datasets:

### Content Dataset

The content dataset contains information about social media posts,
including:

- Content ID
- Topic
- Content Type
- Hook Type
- Posting Time
- Caption Style
- Likes
- Comments
- Shares
- Saves
- Retention Rate
- Followers Gained

### Comments Dataset

The comments dataset is used to analyze audience responses and classify
comments as:

- Relatable
- Neutral

## 5. Engagement Analysis

An engagement score was created using the following formula:

Engagement Score =

Likes
+ (3 × Comments)
+ (5 × Shares)
+ (5 × Saves)

Shares and saves receive higher weights because they represent stronger
content interaction and distribution signals.

The engagement score was used to compare different content
characteristics.

---

## 6. Viral Analysis

A viral score was created using:

Viral Score =

Likes
+ (3 × Comments)
+ (5 × Shares)
+ (5 × Saves)
+ (2 × Retention Rate)

The score was used to rank content and compare viral performance across
topics.

The analysis identified the top-performing content and topics based on
the calculated viral score.

---

## 7. Audience Relatability Analysis

Comments were cleaned and analyzed using a rule-based approach.

Comments were classified into:

- Relatable
- Neutral

The percentage of relatable comments was calculated overall and by
topic.

This analysis provides an indication of how strongly audiences connect
with different types of content.

---

## 8. A/B Testing

Statistical testing was performed to compare:

### Content Format

Short Video vs Long Video

### Hook Type

Visual vs Text

### Posting Time

Different posting-time groups were compared using ANOVA.

For statistical tests:

- p-value < 0.05 indicates a statistically significant difference.
- p-value >= 0.05 indicates that the observed difference is not
  statistically significant.

The actual results are available in the project notebook.
